# Tienda Mamá

Catálogo web de productos de higiene personal, perfumes y más.

## Cómo agregar productos

Edita el archivo `data/productos.json` y agrega productos con esta estructura:

```json
{
  "id": 9,
  "nombre": "Nombre del Producto",
  "categoria": "Categoría",
  "precio": 0.00
}
```

**Categorías disponibles:** Perfumes, Jabones, Shampoo, Crema, Desodorante, Cuidado Facial, Cuidado Corporal, Maquillaje, Accesorios

## Ver el catálogo

Abre el archivo `index.html` en tu navegador o visita la página en GitHub Pages.
